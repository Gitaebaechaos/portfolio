## 🧑‍🌾 Assignment 1: Farm 시뮬레이션 게임

**SimFarm**은 농장을 경영하며 작물을 재배하고 수확하는 **턴 기반 시뮬레이션 게임**입니다.

### 🌱 시스템 구조

- **Item 클래스** 기반으로 모든 객체 설계  
  (나이, 성숙 나이, 죽는 나이, 금전적 가치 포함)
- 상속 구조:
  - `Food` → `Grain`, `Apple`  
  - `Weed`, `UntilledSoil`, `Soil` 등 환경 요소도 모두 `Item`으로 관리

### 🧭 주요 게임 메커니즘

- `Field`: 2차원 배열로 구성된 밭
  - 초기 상태는 모두 경작된 땅(Soil)
  - 매 턴 `tick()` 호출 시 아이템 나이 증가, 잡초 등장 확률 20%
- `Farm`: 자금 기반 경영 시스템
  - 플레이어는 다양한 명령어로 게임 진행

### ⌨️ 명령어 목록

| 명령어 | 기능 설명 |
|--------|-----------|
| `t x y` | 해당 위치 경작 |
| `p x y` | 사과 or 곡물 심기 |
| `h x y` | 작물 수확 및 수익 |
| `s`     | 전체 밭 상태 요약 |
| `w`     | 대기 (턴만 진행) |
| `q`     | 게임 종료 |

> 작물마다 수명 및 가치가 다르며, 전략적으로 수익을 창출하는 것이 핵심입니다.

## 💹 Assignment 2: 주식 시장 시뮬레이션 시스템

**GameStock**은 간단한 주식 시장 생태계를 모델링한 Java 기반 시뮬레이션입니다.

### 🏢 주요 구성 요소

- **ListedCompany (상장 기업)**  
  - 이름, 코드, 현재 주가 등 정보 보유
- **Trade (거래)**  
  - 거래 수량, 기업, 중개인 정보 포함
- **Broker (중개인)**  
  - 사용자로부터 거래 요청을 받아 큐에 저장  
  - **비윤리적 브로커**는 특정 거래를 뒤로 미룸
  - 추천 주식 목록(Watchlist) 관리
- **StockExchange (거래소)**  
  - 여러 중개인의 큐를 순차적으로 처리  
  - 거래 성사 시 주가 변동 적용

### 🔄 시뮬레이션 흐름

1. 중개인이 거래를 등록
2. 거래소가 각 브로커 큐에서 거래를 꺼내 처리
3. 주가 변동 및 거래 성사 여부 판단
4. 윤리적/비윤리적 행위 감지 및 비교
