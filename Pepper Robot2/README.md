### 🏁 결과 및 소감  

- Pepper 로봇의 반응성, 적응력, 인터페이스를 개선하여 **실제 사용자 환경에서 시연 가능 수준**으로 발전시킴  
- 단순 개발을 넘어 **사용자 피드백 기반 시스템 설계 및 유지보수 흐름까지 경험**  
- 클라이언트 및 슈퍼바이저와의 협업을 통해 **요구사항 분석 → 구현 → 시연**의 전 과정을 직접 주도적으로 수행
