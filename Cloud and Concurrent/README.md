### 🗓️ 작업 기간  
2023.07.07 ~ 2023.11.05

### 👤 작업 인원  
1명

### 🛠️ 사용 툴

- Cloud 환경 (AWS 등)

### 🧩 프로젝트 개요  

이 프로젝트는 **Cloud와 Concurrent Programming(동시성 프로그래밍)** 개념을 실제 사례에 적용하기 위한 시도로,  
**Uber와 유사한 시스템(Nüber)**을 대상으로 **문서화 및 자바 구현**을 수행한 프로젝트입니다.  

- **목표**: 실시간 동시 예약 처리와 클라우드 기반 확장 가능 아키텍처에 대한 이해  
- **핵심 주제**: 멀티스레딩, 사용자 역할 분리, 클라우드 보안, 규제 시뮬레이션

### 💻 Assignment 2: Nüber - 자바 코딩 구현  

#### 🎯 과제 목적  
정부 규제로 인해 **도시별 운전자 수가 제한**되는 상황을 가정하고,  
해당 규제가 플랫폼 운영에 미치는 영향을 **시뮬레이터**로 구현

#### 🧩 구현 요소  
- **예약 시스템**: 사용자 요청이 동시에 들어와도 안정적으로 처리되도록 **멀티스레딩** 적용  
- **동시성 처리**: `Thread`, `ExecutorService`, `synchronized` 등을 사용하여 **경합 조건 방지**  
- **종료 조건**: 모든 예약이 완료되면 시스템이 자연스럽게 종료되도록 설계  
- **규제 적용**: 도시마다 운전자 제한을 두고, 초과 시 대기 또는 요청 거절 처리

#### 🔄 예시 흐름  
1. 고객 A, B, C가 동시에 호출 요청
2. 도시에 배정된 운전사 수가 부족한 경우 대기 또는 실패
3. 운전사가 수락 → 이동 시뮬레이션 → 예약 종료
4. 모든 요청 완료 시 시스템 종료

  **현실적인 시뮬레이션 구현 및 분석 능력 강화**
