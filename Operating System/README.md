## 🧭 프로젝트 개요

본 프로젝트는 **팀 회의용 카운트다운 타이머 개발**과  
**운영체제 구조 분석 및 재설계**라는 두 가지 과제로 구성되었습니다.

각 과제는 실용성과 성능 최적화를 목표로,  
현실적인 문제 해결을 위한 소프트웨어 및 시스템 설계를 수행하였습니다.

---

## ⏳ Assignment 1: 팀 회의용 카운트다운 타이머 개발

### ✅ 프로젝트 목적  
회의 시간 관리를 위해 **정해진 시간 동안 카운트다운**을 수행하고,  
**시간 초과 시 알람 경고**를 제공하는 실용적인 타이머 툴을 개발하였습니다.

### 🧩 주요 기능

- 사용자가 설정한 시간 기준으로 **카운트다운 시작**
- 시간이 종료되면 **경고음 또는 시각적 알림 제공**
- **직관적인 UI**로 누구나 쉽게 사용 가능
- 팀 프로젝트 회의, 발표 준비 등 시간 관리에 활용

### 📌 특징

- **Python 기반의 간단한 데스크탑 유틸리티**
- 업무 및 학습 환경의 시간 효율성 개선
- 실제 회의 시간 측정 및 피드백을 통해 반복 개선

## 🖥️ Assignment 2: 운영체제 및 툴체인 재설계

### ✅ 프로젝트 목적  
운영체제의 **핵심 구성 요소**를 분석하고,  
특정 시나리오에 맞게 최적화된 구조를 설계하였습니다.

### 🔍 조사 및 분석 내용

| 구성 요소 | 주요 분석 내용 |
|-----------|----------------|
| 프로세스 스케줄링 | 선점형 vs 비선점형, 멀티코어 환경에서의 효율성 |
| 메모리 관리 | 가상 메모리, 페이지 교체 알고리즘, 메모리 단편화 해결책 |
| 파일 시스템 | FAT32, ext4 등 비교 및 현대적인 접근 방식 연구 |

### 🏗️ 재설계 제안

- 특정 상황(예: 실시간 처리, 임베디드 시스템 등)에 최적화된 운영체제 구조 제안
- **커널 구조 단순화**, **I/O 효율성 개선**, **캐시 활용 극대화**
- 현대적인 툴체인(예: GCC, LLVM)과의 연계 전략 포함

### 📌 결과

- 실제 시스템 요구사항에 맞춘 설계안을 제시
- 시스템 성능 향상과 자원 활용 극대화를 목표로 구성
