## 🤖 Pepper Robot - 휴머노이드 인터랙션 향상 프로젝트

### 🗓️ 작업 기간  
2023.07.03 ~ 2023.11.28

### 👥 작업 인원  
4명

### 🛠️ 사용 툴  
- Choreographe  
- Pepper Robot SDK  
- Python / Blockly

---

### 🧩 프로젝트 개요  

이 프로젝트는 **Unisa Health Clinic** 내에서 **Pepper 로봇의 상호작용 기능**을 향상시키기 위한 것으로,  
전 학기 팀이 개발한 베이스 프로젝트를 이어받아 기능을 개선하고 확장하는 것을 목표로 하였습니다.

- **목표**: 사용자와의 **자연스러운 대화**, **개인화된 응대**, **피드백 수집**, **안내 기능 향상**을 통한 **더 나은 클리닉 경험 제공**
- **결과물**: 클라이언트와의 대화, 피드백 수집, 클리닉 내 내비게이션이 가능한 지능형 Pepper 시스템 구축

---

### 🔧 담당 역할 및 기여도  

- **총 기여도**: 약 25%  
- **담당 기능**:
  - 📍 **피드백 시스템 설계 및 구현**  
    → 사용자의 반응을 기록하고 분석하여 Pepper가 학습하고 개선된 응답을 할 수 있도록 기능 설계  
  - 🤝 **기획 및 애자일 회의 참여**  
    → 주간 스프린트 회의에 적극 참여해 기능 우선순위 및 개선점 도출  
  - 📢 **클라이언트 미팅 대응 및 요구사항 정리**  
    → 클라이언트·슈퍼바이저 의견을 반영한 기능 개선  
  - 🧪 **박람회 시연 및 설명 담당**  
    → 프로젝트 결과물을 실제 시연하며 기술과 구조 설명 수행

---

### 💡 주요 기능 요약  

| 기능 | 설명 |
|------|------|
| 👋 인사 및 대화 | 방문자 인식 후 이름 기반 인사, 대화 흐름 유지 |
| 🧠 피드백 수집 | 사용자 만족도 피드백 입력 및 내부 DB 기록/분석 |
| 📍 위치 안내 | 특정 진료실로 안내하며 방향 및 목적지 설명 |
| 🧩 사용자 인터페이스 | 다양한 언어와 직관적 UI로 사용자 편의성 향상 |
| 📊 지속 학습 | 이전 피드백 기반 반응 개선 로직 탑재 |
