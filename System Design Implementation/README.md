## 🚗 Assignment 1: 주차 모니터링 시스템 (PMS)

### 🔹 프로젝트 개요
본 프로젝트는 차량 번호판 인식(LPR) 카메라와 GPS 기술을 활용하여 특정 구역의 차량 주차 상태를 모니터링하는 **주차 모니터링 시스템(PMS)**을 개발하는 것을 목표로 합니다.  
주차 허가 없이 주차된 차량을 감지하여 **과태료를 부과하는 기능**을 포함합니다.

---

### 🔸 주요 기능 (Use Cases)

#### UC01 - 차량 등록
- 운전자가 차량 번호판을 등록
- 주차 위치 및 시간 설정
- 신용카드로 결제
- 모바일 앱 또는 PMS 키오스크에서 가능

#### UC02 - 차량 모니터링
- PMS 차량이 주기적으로 주차장을 순찰
- LPR 카메라로 차량 번호판 인식
- 주차 위치 및 시간 자동 기록

#### UC03 - 과태료 부과
- PMS 차량이 무단 주차 차량을 감지하면 경고 발생
- 관리자가 번호판 확인 후 과태료 부과
- 시스템에 기록하고 영수증을 차량 유리에 부착

#### UC04 - 실시간 통계 및 모니터링
- 운영자는 대시보드를 통해 다음 정보 확인 가능:
  - 시간대별 주차 차량 수
  - 발급된 과태료 수
  - PMS 차량의 이동 경로
- 최소 5분마다 정보 갱신

---

### 🔸 시스템 요구사항

#### 🧩 사용성 (Usability)
- 주차 관리자용 UI는 **태블릿 환경에 최적화**
- **야외에서도 가독성**이 높아야 함

#### ⚙️ 성능 (Performance)
- 차량 속도 10km/h 이하일 경우
- **5m 거리에서 0.5초 이내 번호판 인식** 가능

#### 📦 확장성 (Scalability)
- **10만 건 이상**의 과태료 및 차량 사진 데이터 저장 가능
- 최소 **100대의 PMS 차량 동시 지원**

#### 📋 비즈니스 규칙 (Business Rules)
- 과태료 관련 사진, GPS 위치, 타임스탬프는 **최소 5년간 보관**
- 차량이 진입한 후 **10분 이내 주차 허가 등록**, 초과 시 과태료 부과

---

### 🔸 미래 확장성 (Future Evolutions)
- 현재는 이동형 LPR 카메라 사용 중
- **향후 고정형 LPR 카메라 설치 계획**
  - 더 높은 인식률 확보 가능
  - 일부 모델은 **클라우드 기반 알고리즘** 사용으로 네트워크 대역폭 요구 증가

## 💬 Assignment 2: 질문 답변 시스템

### 🔹 프로젝트 개요
이 프로젝트는 사용자가 **자연어로 입력한 질문**을 분석하고,  
저장된 질문-답변 데이터베이스에서 **가장 유사한 질문을 찾아 적절한 답변을 제공**하는 간단한 질문 답변 시스템입니다.

---

### 🔸 주요 기능 (Use Cases)

#### UC1 - 시스템 시작 (Welcome)
- 시스템 실행 시 사용자에게 환영 메시지 출력

#### UC2 - 질문 입력 및 응답 (Ask Question)
- 사용자는 한 문장으로 질문을 입력
- 시스템은 입력된 질문을 저장
- 기존 질문 DB에서 **가장 유사한 질문을 탐색**
- 해당 질문과 연결된 **답변을 제공**
- 종료 명령 전까지 반복

#### UC3 - 시스템 종료 (Quit)
- 사용자가 **빈 줄(공백)**을 입력하면
- 시스템은 종료 메시지를 출력하고 실행 종료

---

### 🔸 데이터 예시 (Sample Data)
```json
[
  {
    "question": "What day is today?",
    "answer": "Monday"
  },
  {
    "question": "What is the weather like today?",
    "answer": "Same as yesterday."
  }
]
```
