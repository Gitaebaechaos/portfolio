## 🤖 PMS 시스템 & 질문 답변 시스템 개발 프로젝트

### 📅 작업 기간  
2021-07-30 ~ 2021-11-12

### 👥 작업 인원  
4명

### 🛠️ 사용 툴 및 기술 스택  
- **개발 언어:** Python  
- **개발 환경:** IDLE  
- **문서화:** 보고서 및 발표 자료 작성  

---

### 📌 프로젝트 개요  

이 프로젝트는 두 개의 과제(Assignment 1, 2)로 구성된 팀 프로젝트입니다.  
초기에는 4명이 함께 **Volatility 개념에 기반한 PMS 시스템**과 **질문 답변 시스템**의 기능과 구조를 설계하고, 보고서를 작성하였습니다.

- **Assignment 1 (PMS 시스템)**  
  차량 번호판 인식을 통해 **주차 위반 차량을 감지하는 시스템**입니다.  
  팀원들과 함께 시스템 구조를 나누어 구현하였으며, 각 기능은 협업을 통해 통합되었습니다.

- **Assignment 2 (질문 답변 시스템)**  
  사용자의 질문과 **유사한 질문을 찾아 자동으로 답변을 제공하는 시스템**으로,  
  이 기능은 **Python을 사용해 혼자서 전체 구현**을 담당하였습니다.

---

### 🧩 작업 분배 및 본인 기여

- 🔹 **Assignment 1 (PMS 시스템):**  
  - 팀원들과 협력하여 시스템 구조 설계 및 기능 분담  
  - 약 **25%의 기여도**로 설계, 자료조사, 보고서 작성 등에 참여

- 🔹 **Assignment 2 (질문 답변 시스템):**  
  - **100% 단독 개발**  
  - 시스템 기획부터 **핵심 알고리즘 구현, 테스트, 오류 수정, 최적화**까지 전체 수행  
  - 유사 질문 매칭 로직, 답변 자동 추천 기능 구현  
  - 코드의 **안정성과 효율성을 고려한 최적화** 진행

### 📈 핵심 성과

- Volatility 개념에 기반한 시스템 설계 경험  
- Python 기반의 실제 응용 시스템(질문 답변 시스템) 구현 역량 강화  
- 단독 개발을 통해 기능 설계, 로직 구현, 테스트까지 전체 개발 프로세스를 경험
