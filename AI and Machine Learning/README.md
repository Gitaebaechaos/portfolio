### 📌 프로젝트 소개  
이 프로젝트는 **Machine Learning 기법**을 활용하여 주어진 **이진 분류(Binary Classification)** 문제를 해결하기 위한 **신경망 모델을 구축**하는 것이 목적입니다.

- **Logistic Regression**, **Decision Tree**, **Neural Network** 모델을 활용하여 예측 성능을 비교 분석하였으며,  
- 각 모델의 **하이퍼파라미터 튜닝**과 최적화를 통해 **모델 정확도 향상**을 추구했습니다.  
- 성능 평가는 정밀도, 재현율, F1-score 등의 다양한 지표를 기준으로 진행하였습니다.

### 📋 프로젝트 개요

이 프로젝트는 실제 데이터를 기반으로 한 **이진 분류 문제(Binary Classification)**를 해결하기 위해  
다양한 머신러닝 모델을 구축하고, 각 모델의 **성능을 비교 및 분석**하는 것을 목표로 하였습니다.

총 5개의 Task로 구성되며, **데이터 전처리부터 모델 성능 비교 및 추천까지의 전체 머신러닝 워크플로우**를 포함합니다.

---

### 🔹 Task 1. 데이터 준비

- **목표:** 모델 학습을 위한 데이터를 준비하고 전처리 수행
- **내용:**  
  - 주어진 데이터를 로드하고 필요한 열만 추출  
  - `X` (특성)과 `Y` (타겟)으로 분리  
  - 결측값 제거 및 정제

---

### 🔹 Task 2. 로지스틱 회귀 모델 학습

- **목표:** 로지스틱 회귀 모델 학습 및 성능 평가
- **세부 설정:** `max_iter=2000`
- **결과:**  
  - 훈련 데이터:  
    - F1-score: **89%**  
    - 정확도: **87%**  
  - 테스트 데이터에서도 유사한 성능을 보여 **과적합/과소적합 없이 안정적인 예측력** 확보

---

### 🔹 Task 3. 결정 트리 모델 학습

- **목표:** 결정 트리 모델 학습 및 최적 하이퍼파라미터 탐색
- **결과:**  
  - 교차 검증을 통해 얻은 정확도: **94~95%**  
  - F1-score: **96~97%**  
  - **높은 예측 성능**과 **모델의 안정성** 확인

---

### 🔹 Task 4. 신경망 모델 학습

- **목표:** 간단한 신경망 모델 설계 및 학습
- **구성:**  
  - 2개의 은닉층 + 1개의 출력층  
- **결과:**  
  - 훈련 정확도: **95%**  
  - 검증 정확도: **96%**  
  - 테스트 정확도: **96%**  
  - 과적합 없이 **우수한 일반화 성능**을 달성

---

### 🔹 Task 5. 모델 비교 및 최적 모델 선정

- **목표:** 각 모델 성능 비교 및 최적 모델 추천
- **비교 대상:** 로지스틱 회귀 vs 결정 트리 vs 신경망  
- **추천 모델:**  
  - **신경망 모델 (정확도 96%)** → 가장 뛰어난 성능을 보임  
- **총평:**  
  - 세 모델 모두 높은 정확도와 안정적 성능을 보였으며,  
  - 프로젝트는 고급 머신러닝 기법을 활용한 **모델 성능 최적화 및 비교 분석의 좋은 사례**가 되었습니다.
