### 📌 프로젝트 소개  
이 프로젝트는 **Machine Learning 기법**을 활용하여 주어진 **이진 분류(Binary Classification)** 문제를 해결하기 위한 **신경망 모델을 구축**하는 것이 목적입니다.

- **Logistic Regression**, **Decision Tree**, **Neural Network** 모델을 활용하여 예측 성능을 비교 분석하였으며,  
- 각 모델의 **하이퍼파라미터 튜닝**과 최적화를 통해 **모델 정확도 향상**을 추구했습니다.  
- 성능 평가는 정밀도, 재현율, F1-score 등의 다양한 지표를 기준으로 진행하였습니다.
