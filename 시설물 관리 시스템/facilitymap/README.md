## 🗺️ 시설물 위치 정보 관리 시스템

### 📅 작업 기간  
2025-07-01 ~ 2025-07-23

### 👤 작업 인원  
1명 (개인 프로젝트)

### 🛠️ 사용 툴 및 기술 스택  
- **IDE:** Eclipse  
- **테스트 도구:** Postman  
- **DB 도구:** MySQL Workbench  
- **Backend:** Java + Spring Boot  
- **Frontend:** HTML, JavaScript, 지도 API (지도 클릭 이벤트 활용)  
- **DB:** MySQL (JPA 사용)  
- **아키텍처:** MVC 기반

---

### 📌 프로젝트 개요  

본 프로젝트는 **공공기관에서 활용 가능한 시설물 위치 정보 관리 시스템**입니다.  
사용자가 **지도 위에서 마커를 클릭하면 해당 위치의 위도/경도 좌표를 받아**,  
이를 기반으로 **시설물 정보를 등록 및 조회**할 수 있는 기능을 제공합니다.

---

### 📂 주요 기능  

- 🗂️ 시설물 등록, 조회 기능  
- 📍 지도 클릭 시 좌표(위도/경도) 자동 수집  
- 🔗 Spring Boot + JPA를 통한 MySQL DB 연동  
- 🧭 간단한 프론트 구현 (HTML + JS)  
- ⚙️ Postman을 활용한 API 테스트 수행

---

### 🧩 기술적 포인트  

- **Spring Boot MVC 아키텍처** 기반으로 구성  
- **JPA로 DB 연동**하여 Entity 중심의 개발 구조  
- **지도 API 연동**으로 좌표 클릭 이벤트 구현  
- 단일 프로젝트로 백엔드 + 프론트엔드 + DB 연동까지 모두 직접 구현

---

## 🔹 주요 기능

### 🗺️ 지도 연동
- 사용자가 실제 지도를 통해 시설물의 위치를 직접 지정할 수 있도록 구현
- 클릭한 위치의 좌표값을 자동으로 받아와 저장

### ➕ 시설물 등록 기능 (Create)
- 시설물 이름, 유형, 설명 등의 정보를 입력
- 지도에서 위치를 선택하여 함께 저장

### 📋 시설물 목록 조회 (Read)
- 등록된 모든 시설물 정보를 리스트 형태로 확인
- 목록에서 시설물을 선택하면 지도에서 해당 위치로 이동

### ✏️ 시설물 정보 수정 (Update)
- 기존에 등록된 시설물의 정보를 수정 가능
- 위치, 이름, 설명 등 모든 항목을 갱신 가능

### 🗑️ 시설물 삭제 기능 (Delete)
- 불필요한 시설물을 삭제하여 목록 정리 가능

---

## 🔹 사용 방법

1. 웹 브라우저에서 시스템 접속 (예: `http://localhost:8080`)
2. 지도에서 시설물을 추가하고 싶은 위치를 클릭
3. 등록 폼에 시설물 정보 입력 후 저장
4. 메인 페이지에서 등록된 시설물 목록 확인
5. 수정 버튼 클릭 시 정보 수정 가능
6. 삭제 버튼 클릭 시 해당 시설물 삭제

---

## 🔹 개발 목적

사용자가 **시각적으로 위치 기반 정보를 직관적으로 등록/관리**할 수 있는 시스템을 구현하여,  
**실무에서 사용할 수 있는 CRUD + 지도 기반 웹 애플리케이션**을 완성하는 것이 목표였습니다.
