### 📌 프로젝트 개요  

해당 프로젝트는 **C++ 언어**를 활용하여 개발한 두 가지 시스템으로 구성되어 있습니다:

1. **"Sushi Slam!"** – 카드 드래프팅 방식의 커맨드라인 기반 게임  
2. **환자 관리 시스템** – 실시간 생체 신호 기반 경고 시스템

두 과제 모두 **실시간 데이터 처리와 사용자 상호작용**을 중심으로 설계되었으며,  
C++의 객체지향 구조를 적극 활용하여 구현하였습니다.

---

### 🎴 Assignment 1: Sushi Slam! 게임 개발

- **게임 형식**: 2인용 커맨드라인 카드 드래프팅 게임  
- **게임 진행 방식**:
  - 플레이어는 매 라운드마다 **스시 카드 한 장을 선택**
  - 총 3라운드 동안 점수를 경쟁
  - 스시 종류마다 **독자적인 점수 규칙**이 적용됨
- **구현 요소**:
  - 카드 덱 셔플링, 카드 선택 로직, 점수 계산
  - 게임 상태 출력 및 사용자 입력 처리
- **특징**:
  - 유명 게임 **"Sushi Go!"**를 모티브로 하되, **새로운 규칙과 구조**를 창의적으로 도입
  - 콘솔 기반으로 직관적이고 빠른 게임 플레이 제공

### 🩺 Assignment 2: 환자 관리 시스템 개발

- **시스템 목적**:
  - 환자의 생체 신호를 주기적으로 수집하고 위험 수준에 따라 **경고 알림 제공**
- **기록 항목**:
  - 체온, 심박수, 혈압, 호흡수 등
- **경고 레벨 기준**:
  - Green → 정상  
  - Yellow → 경고  
  - Orange → 주의  
  - Red → 위급  
- **질병 유형별로 다른 경고 기준** 적용
- **기능 구성**:
  - 환자 데이터의 파일 저장/불러오기 기능  
  - 실시간 모니터링 및 경고 출력  
  - 데이터 클래스 및 구조화된 환자 정보 관리
