## 📌 프로젝트 설명

본 포트폴리오는 다양한 프로젝트를 **GitHub**에 체계적으로 정리해놓은 결과물입니다.  
각 프로젝트는 독립된 폴더로 구성되어 있으며, **README.md 파일**을 통해  
각 작업물에 대한 간단한 소개와 구조, 사용 기술 등을 확인할 수 있습니다.

- **대용량 파일**은 `.zip` 형식으로 업로드하여 저장소 최적화를 고려하였으며  
- **일반 소스 파일**과 자료들은 폴더 구조에 따라 정리되어 있어 접근이 용이합니다  
- 모든 프로젝트에는 간단한 **설명 파일**이 포함되어 있어 전체 흐름을 이해하기 좋습니다

---

### 📁 폴더 구조 예시

각 폴더에는 다음과 같은 형태로 설명이 포함되어 있습니다:

📂 Project_Name/<br>
├─ 📄 README.md → 프로젝트 개요 및 핵심 기능 설명<br>
├─ 📁 src/ → 실제 코드 파일<br>
├─ 📁 그 외 다른 파일들<br>
└─ 📦 project.zip → 전체 압축 파일 (해당 시)<br>
